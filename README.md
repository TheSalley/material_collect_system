## 客户资料与 Banner 存储

- 客户基础信息复用 `page_config`，保留 `page_id = 900000001`
- Banner 收集复用 `page_config`，保留 `page_id = 900000002`
- Banner 图片通过现有图片上传接口写入站点媒体库

## 预设内容包接口

- 管理端 `/admin/preset`：维护行业分类与内容包，内容包以 JSON 保存 `texts` 与 `images`。
- 接口使用 `/api/presets/list|add|update|delete` 与 `/api/presets/categories/*`，不再包含 `widget_type`、`field`、`lang`。
- 页面编辑时在组件内使用“预设素材”按包手动挑选图片与文案，不再自动套用空白字段。
- 开发环境默认请求 `http://localhost:3501`，可用 `VITE_PRESET_API_BASE_URL` 覆盖；生产环境默认走 `/fe`。
